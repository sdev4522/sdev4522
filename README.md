## How I Approach Engineering

I like working across the entire system rather than treating deployment as someone else's problem.

```
Frontend
   ↓
Application / API
   ↓
Database + Cache
   ↓
Web Server
   ↓
Linux
   ↓
Production
```

That means I'm comfortable debugging problems that cross boundaries — from a frontend request and API response all the way down to Nginx, PHP-FPM, permissions, DNS, SSL, or database configuration.
